Native desktop runtime generated by `scripts/prepare-desktop-runtime.py`.

Release builds populate this directory with:

- `pdfium/`: the platform PDFium shared library used to render scanned PDF pages.
- `licenses/`: PDFium and third-party license texts.
- `runtime-manifest.json`: pinned versions + per-file SHA-256 of the bundle.

Tesseract/tessdata are no longer bundled (ADR 0016): image/scan OCR runs
through a vision LLM configured via `FILECONV_OCR_*`.

Generated binaries are intentionally gitignored.
